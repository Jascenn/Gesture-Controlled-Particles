# Security Policy

## Supported versions

Security fixes are applied to the latest code on the `main` branch.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability, exposed credential,
or privacy issue. Use the repository's **Security > Advisories > Report a
vulnerability** flow:

https://github.com/Jascenn/Gesture-Controlled-Particles/security/advisories/new

Include the affected browser, reproduction steps, impact, and any suggested
mitigation. Remove API keys, camera images, and personal information from logs
and screenshots.

Reports are handled on a best-effort basis. Please allow time for validation
and a coordinated fix before public disclosure.
